# NL2SQL模块工作规则

2026-11-07。补充[根开发约定](../../../AGENTS.md)，本目录遵循根开发约定。

## 最小入口

读根AGENTS、[产品任务板](../../../docs/product/TASKS.md)，按任务读取SQL proposal / SafetyGate / 执行器及契约。评测任务读[测试策略](../../../docs/product/TESTING.md)。修改执行边界时记录验证结果。

## 执行边界

- 模型只生成候选，当前SafetyGate批准后才由只读执行器执行；不得通过改调用约定绕过。
- 当前单表模式拒绝JOIN、子查询、多语句、写操作、危险函数及未授权对象；扩大能力先明确授权范围、版本化契约并独立安全验证。
- 结构化输入严格验证未知字段/枚举和条件必填，失败关闭。接入新数据源仍需重新检查Schema授权，不能复用固定Chinook假设。
- 不增加重试/Token/时长/费用或扩大模型/外发掩盖失败。普通测试离线、无需真实Key，真实模型批次另授权。
- 按任务范围跨模块修改，保护其他工作区；没有目录所属角色审批链。

## 交付

按根AGENTS分级验证；PR或交接记录实际结果、缺口和下一步，状态变化再更新唯一任务板。SQL执行/安全边界保留一次精确最终head独立复核，不更新旧角色板。
