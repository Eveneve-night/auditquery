# AuditQuery 产品范围

目标：可审计的本地只读数据问答。用户可以核对 SQL、结果、来源与实际工具事件；缺证据拒答，缺信息澄清。

当前实现：固定 Chinook 单表只读执行、候选提案与安全门、澄清恢复/预算、文档页级证据及确定性摘录、身份/CSRF、加密凭据、事务数据源 Registry 和离线预览。

尚未实现：受控 SQLite Adapter 的真实连接/Schema/查询、数据源管理 HTTP、任意授权库问数闭环、完整 drain/停用链、模型综合答案、跨源融合和 JOIN。

首个里程碑是 SQLite 接入→验证→同步→授权→发布→查询→来源→停用；第二独立实例用于验证切换。PostgreSQL 与异构数据库是后续能力，不作为已有功能。

在线支持管理员配置的 OpenAI 兼容 Chat Completions 服务、模型和不透明凭据；百炼是可选兼容配置，无隐式 fallback。其他原生协议尚未支持，详见 [配置与安全边界](MODEL-SERVICES.md)。普通开发离线。测试数量不等于业务准确率；没有真实测量时不宣称性能或客户收益。
