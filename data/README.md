# 数据与样例

- `raw/chinook-v1.4.5/`：供固定领域问数使用的只读 SQLite 样例；见[来源](raw/chinook-v1.4.5/SOURCE.md)和[许可证](raw/chinook-v1.4.5/LICENSE.md)。
- `raw/pdf/`：供文档检索与引用验证使用的合成 PDF。
- `public-business/`：合成订单和运维数据的建库脚本与种子，不代表已支持任意数据库接入。
- `schema/`、`schema-linking/`、`manifests/`：Schema、定位样例、资产版本和完整性记录。

实际实例数据必须放在仓库外。公开资产的授权范围见[资产许可](../docs/product/ASSET-LICENSES.md)。
